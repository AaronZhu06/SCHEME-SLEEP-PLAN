# 睡前日程

每天睡前花几分钟，用时间块把明天排好；第二天随手打分，晚上收尾时把没做完的顺延。
一个网页文件，装到 iPhone 主屏幕后可以离线使用，数据只存在手机里。

网址：<https://aaronzhu06.github.io/SCHEME-SLEEP-PLAN/>（在仓库的 Settings → Pages 里开启后可用）

## 装到 iPhone 上

1. 用 **Safari** 打开上面的网址。
2. 点底部的分享按钮，选「添加到主屏幕」。
3. 以后都从主屏幕上的「睡前日程」图标打开。第一次打开需要联网，之后断网也能用。

主屏幕图标里的数据和 Safari 标签页里的数据是分开的，导入记录、日常使用都请在图标里做。

网页有更新时，打开一次会在后台下载新版本；从后台把它划掉再打开，就是新的了，数据不受影响。

## 导入以前的记录

在图标里打开「设置 → 导入备份或以前的记录」，选择 `.json` 文件即可。
文件里有的日子会覆盖同一天的安排，其他日子不受影响。

## 备份

数据只存在这台手机的这个网页里，不会上传。删掉主屏幕图标、或者清除 Safari 网站数据，会把它一起删掉。
在「设置 → 导出备份」可以把全部数据存成一个 `.json` 文件放到「文件」App 里；换手机时再导入即可。
「导出表格」会生成 CSV，能用 Excel 打开，列和以前的日程表一样：日期、开始、结束、安排、分类、备注、完成情况。

## 主要功能

- **明天**：晚上 9 点后打开直接进这一页。可以复制今天再改，也可以从空白开始。
- **加一块**：先写做什么（或者点常用块、待办池里的事），再用两把刻度尺调开始时间和时长，每格 1 分钟（设置里可改成 5、10、15、30 分钟）。按住 ＋ / − 会越调越快；点上面的大号时间，可以直接用 iPhone 的时间滚轮输入。和别的块重叠会标红。
- **今天**：红线标出现在的时间，点一块给它打分（没做 / 25% / 50% / 75% / 100%）。
- **今天收尾**：一次性给今天打分，没做完的选「顺延到明天」「放进待办」或「不管了」，再写一句心得。
- **待办池**：想到要做但还没排进时间的事，可以设截止日期，一点「排进明天」就放进明天的时间轴。
- **复盘**：每天的完成率、各分类用了多少时间、每一天的心得。
